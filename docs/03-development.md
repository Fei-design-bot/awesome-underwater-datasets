# 维度 3 · 任务发展与技术发展

## 3.1 任务场景演进

| 时期 | 场景 | 技术 |
|---|---|---|
| 2017–2020 | URPC 竞赛时代：光学检测起步，4 类海参/海胆/扇贝/海星 | YOLOv3、两阶段检测起步，数据以竞赛为主 |
| 2021 | 数据集建设：DUO 去重整合、UDD 4K 养殖场、AUDD 扩增 | Poisson GAN 数据扩增（AquaNet, TCSVT'21）；YOLOv3 声纳 |
| 2022–2023 | 轻量化与工程落地探索 | LighterDet、UOD-FPN、YOLO-lite 等轻量检测 |
| 2024 | 复杂退化建模：AAAI 出现相关研究 | AMSP-UOD（涡旋卷积）；YOLOv8 大规模改进；增强+检测开始融合 |
| 2025 | 多模态与统一框架：垃圾/实例分割数据集兴起 | LUIEO 统一增强检测；DebrisVision（ICCV）多模态；扩散/物理先验增强 |
| 2026 | 顶会顶刊集中发表：检测、增强、基础模型、3D 各方向均有进展 | RHCNet（CVPR）；ViT/Mamba/状态空间；AquaticCLIP（VLM）；Wat3R（ECCV 3D）；WaterFlow（物理先验） |

## 3.2 技术发展主线

| 维度 | 演进路径 |
|---|---|
| 骨干演进 | Darknet/YOLOv3 → YOLOv5/v8 → YOLOv11 → Transformer/ViT → Mamba/状态空间 |
| 任务建模 | 纯检测 → 增强+检测联合 → 多任务（检测+增强+分割）→ 视觉语言预训练 → 3D 几何 |
| 数据策略 | 竞赛数据 → 去重/扩增（GAN）→ 合成到真实（DebrisVision）→ 自监督物理先验 |
| 评估场景 | 光学 4 类 → 10 类通用 → 垃圾/声纳/鱼类/视频/3D 多场景 |

## 3.3 场景分类（含医疗类比）


水下检测与**医疗影像**同属「退化/低对比 + 小目标 + 域迁移」问题，可类比学习：

| 水下场景 | 医疗类比 | 共性挑战 |
|---|---|---|
| 浑浊/低光照增强 | CT 去噪/对比度增强 | 退化图像恢复 |
| 小目标检测（海参/扇贝） | 微小病灶/结节检测 | 小目标漏检 |
| 声纳目标检测 | 超声/低 SNR 成像 | 强噪声下检测 |
| 合成→真实迁移（DebrisVision） | 跨域/跨模态迁移 | 域迁移泛化 |
| 呼吸/运动错位 | 相位配准（如 NCCT→CECT） | 数据对齐 |
